# SkinSutra

SkinSutra is an AI-powered skin disease detection system that uses deep learning and computer vision techniques to analyze skin images and predict possible skin conditions.

---

## Features

- Skin disease image classification
- AI-powered prediction system
- Fast image processing
- User-friendly interface
- Deep learning model integration

---

## Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Flask / Streamlit

## Installation

### Clone the Repository

```bash
git clone https://github.com/sparsh0116/SkinSutra.git
cd SkinSutra
```

---

### Create Virtual Environment

```bash
python -m venv venv
```

Activate the virtual environment:

#### For macOS/Linux

```bash
source venv/bin/activate
```

#### For Windows

```bash
venv\Scripts\activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Project

```bash
python test.py
```

or

```bash
python app/app.py
```
