# SkinSutra

SkinSutra is an AI-powered skin disease detection system that uses deep learning and computer vision techniques to analyze skin images and predict possible skin conditions.

---

## Features

- Skin disease image classification
- AI-powered prediction system
- Fast image processing
- User-friendly interface
- Deep learning model integration

---

## Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Flask / Streamlit
